# Media Placeholders

Drop your actual media files in this folder. Make sure they are named correctly:

## Photos for individual scenes
- `photo-01.jpg` - Welcome scene photo (circle)
- `photo-02.jpg` - Our Story Part 1 (4:3 aspect ratio recommended)
- `photo-03.jpg` - Our Story Part 2 (square aspect ratio recommended)

## Carousel Photos (Scene 5)
- `carousel-1.jpg`
- `carousel-2.jpg`
- `carousel-3.jpg`
- `carousel-4.jpg`
- `carousel-5.jpg`
(4:5 vertical aspect ratio recommended for these)

## Video (Scene 8)
- `video-01.mp4` - Make sure it's web-optimized (e.g. h264)
- `video-01-thumb.jpg` (optional) - Thumbnail for the video

Note: The app will gracefully show a styled placeholder box if these files are missing!
